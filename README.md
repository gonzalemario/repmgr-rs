# repmgr-rs

== Intro
You could describe the original repmgr, as a framework to provide HA capabilities
for postgres. It started long time ago, it's been on production for many year
but its main repository seems dead for quite a long time.

When you think in a HA tool, you probably think in a client-server architecture
that can monitor it's target, maybe register master and slaves, and provide some
failover or redundancy mechanism. All of that can be achieved by repmgr. One of
the valuable things that in *my opinion* makes it so hard to discard and replace
the project by some other modern framework, is repmgr tries to follow the Unix
philosophy: make one simple thing and make it right. Although "right" is arguable
for some, repmgr was able to do simple stuff with postgres clusters like register
a primary and many replicas, provide some sort of cluster status and even
automatic failover.

== Objectives of repmgr-rs

repmgr-rs is a project I started on my own personal guidance and resources that
exists at the moment to fullfil 2 main goals:
 a) learn rust using a real proyect (oh yes, rust will be its main language).
 b) create a personal project I can manage and hopefully share with others.

Despite it's a major endeavour, I reckon it'll give me the push I need to polish
some of my skills I've developed through the years and have fun in the process.
It doesn't aim to replace repmgr in current production systems but that's
something it could be done in the long term though.
